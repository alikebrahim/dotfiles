# Retired Dunst configuration

Retired: 2026-07-30
Original package: `dunst/`
Original target: `~/.config/dunst/`

This package is reference-only after Quickshell became the `org.freedesktop.Notifications` authority. The user Dunst service remained masked and inactive at retirement.

It must not be registered in the Stow catalog, selected by a host profile, linked into `$HOME`, or activated by active session code. Restoring it is a new migration requiring ownership-conflict review, an unsuffixed package path, catalog/profile registration, a Stow plan, and separate deployment approval.
