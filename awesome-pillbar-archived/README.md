# Retired AwesomeWM Pillbar

Retired: 2026-07-30
Original paths: `awesome/.config/awesome/pillbar_init.lua`, `theme_bar.lua`, `ui/`, `services/`, and the dormant `.config/awesome.backup-before-pillbar/` snapshot
Original target: `~/.config/awesome/`

This package-shaped archive preserves the dormant native AwesomeWM bar, popups, helper services, theme aliases, and the earlier pre-Pillbar reference snapshot under `reference/pre-pillbar-awesome/`. Quickshell now exclusively owns the bar, tray, controls, notifications, launcher, switcher, display, and session surfaces. Active AwesomeWM retains window-management logic and `naughty.core` only for local errors.

This archive must not be registered, selected, linked, required, or sourced by active AwesomeWM. Restoring it is a new migration requiring ownership review, an explicit source move back into the active `awesome` package, syntax validation, a Stow plan/apply, and separately approved Awesome activation.
