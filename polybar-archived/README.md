# Retired Polybar configuration

Retired: 2026-07-30
Original package: `polybar/`
Original target: `~/.config/polybar/`

This package is reference-only after Quickshell became the only bar and tray host. It depended on Polybar plus retired helper scripts now stored in `awesome_wm_scripts-archived/`.

It must not be registered in the Stow catalog, selected by a host profile, linked into `$HOME`, or launched by active AwesomeWM code. Restoring it is a new migration requiring an unsuffixed package path, reviewed catalog/profile registration, a Stow plan, and separate deployment approval.
